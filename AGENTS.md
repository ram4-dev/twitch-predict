# Project instructions

## Extension-first UI

Cuando diseñemos UI, pensar y validar primero como extensión de navegador. El popup actual mide 700 × 600 px: priorizar lectura inmediata, jerarquía clara y acciones accesibles dentro de ese espacio. Verificar también anchos compactos de 360 px antes de expandir a web. No depender de hover ni animaciones para comunicar información; respetar `prefers-reduced-motion`.

En una resolución, distinguir siempre el resultado ganador y el perdedor del resultado personal. Mostrar la apuesta, el cobro total (incluye la apuesta recuperada) y la ganancia o pérdida neta con unidades explícitas. No usar solo color para indicar estados. Los showcases usan datos de ejemplo y no ejecutan transacciones.
