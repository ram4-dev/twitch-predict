# Experimental bootstrap only

This program currently implements only config initialization authorized by the
upgrade authority. It does not implement a mint, credits, markets, bets or
claims. Do not deploy or integrate it as a PLOT contract. The program ID in
`Anchor.toml` and source is a public example ID and must be replaced with a
uniquely controlled deployment ID before any deployment. The interface is not
stable. No IDL or on-chain validation is claimed by this checkpoint.
