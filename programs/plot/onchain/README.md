# Experimental bootstrap only

This program currently implements config initialization authorized by the upgrade authority and an
experimental NonTransferable mint initializer. It does not implement credits,
markets, bets or claims. Do not deploy or integrate it as a PLOT contract. The program ID in
`Anchor.toml` and source is a test-only ID and must be replaced with a
uniquely controlled deployment ID before any deployment. The interface is not
stable. No IDL or on-chain validation is claimed by this checkpoint.
